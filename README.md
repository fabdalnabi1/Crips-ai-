# Crips AI

Free-first gaming Shorts project.

## Current status
- Paste YouTube link and check format: implemented in the static preview.
- Select small centered captions and vertical 9:16: UI only.
- Automatic highlight detection, video access, caption rendering and MP4 export: **not implemented or deployed**.
- No video uploads or personal data are included in this public repository.

## Hosting
The static UI can be hosted by GitHub Pages. GitHub Pages cannot process video, download YouTube footage, or run FFmpeg. A separate, authorized processing service is necessary.

## Privacy
Do not commit private videos, personal information, API tokens, private links, or generated clips.

## Development
Open index.html locally to preview. The form intentionally does not claim to generate clips.
